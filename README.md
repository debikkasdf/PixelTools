# Pixel Tools

Нативное приложение для Windows, которое определяет подключённый Google Pixel
через **ADB** или **Fastboot** и показывает сведения об устройстве в интерфейсе
Material 3 Expressive.

Интерфейс построен на **PySide6 / Qt Widgets** и рисуется через `QPainter`.
HTML, QML и встроенный браузер не используются.

## Запуск

```powershell
python -m pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+. Программы `adb`, `fastboot` и `scrcpy` можно положить
в папку `tools/` рядом с приложением или установить в `PATH`.

### Параметры

```powershell
python main.py --theme dark
python main.py --theme light
python main.py --theme system
python main.py --light
python main.py --dark
```

Тема также задаётся переменной окружения:

```powershell
$env:PIXELTOOLS_APPEARANCE = "dark"
python main.py
```

По умолчанию используется системная светлая или тёмная тема. Переключить её
можно кнопкой **M3** в нижней части боковой панели.

### Палитра

Цвета загружаются из `material-you-expressive.json` (экспорт Material Theme
Builder). Если файл отсутствует или повреждён, приложение автоматически
переходит на встроенную пастельную палитру Material 3 и не падает.

Другой файл темы можно указать так:

```powershell
$env:PIXELTOOLS_THEME_FILE = "C:\themes\my-palette.json"
python main.py
```

Поддерживается и старое имя переменной `PIXELTOOLS_THEME`.

## Возможности

- Автоматический поиск устройства при запуске и по кнопке «Обновить».
- Моментальное определение: телефон появляется в интерфейсе сразу после
  ответа ADB/Fastboot, а версия Android, циклы и другие данные догружаются
  в фоне без повторного поиска.
- Material 3 анимации нажатия: ripple от точки клика, плавный state layer и лёгкое сжатие кнопки.
- Определение модели Pixel, кодового имени, поколения, версии Android и API.
- Чтение количества циклов заряда через `dumpsys`, `cmd battery` и sysfs.
- Точное сообщение `Не поддерживается для этой модели` для моделей до Pixel 8.
- Режимы ADB, Fastboot, recovery, unauthorized, offline и sideload.
- Выбор устройства по serial, если подключено несколько.
- Экраны ошибок с диагностикой отсутствующих `adb`/`fastboot`.
- Разделы «Инфо», «Прошивка», «Приложения», «Бэкап» и «Трансляция».
- Прошивка: сведения о сборке, перезагрузка в загрузчик/recovery/fastbootd,
  установка OTA-обновления через sideload.
- Приложения: поиск и фильтр системных пакетов, установка APK, сведения,
  разрешения, остановка, заморозка, очистка данных, экспорт APK и удаление.
- Бэкап: фото, документы, контакты и список пакетов с проверкой и восстановлением.
- Трансляция экрана через `scrcpy` и отдельная панель управления рядом с
  окном телефона: навигация, питание, громкость, выключение звука и снимок
  экрана. Панель следует за окном трансляции и не забирает у него фокус.
- Снимки экрана и настройки звука, качества и поведения окна трансляции.

## Файлы

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа и контроллер нативного окна |
| `qt_material.py` | Палитра, шрифты, QSS и векторные иконки |
| `qt_widgets.py` | Карточки, кнопки, NavigationRail, заголовок |
| `qt_pages.py` | Экраны устройства, ошибок и загрузки |
| `qt_feature_pages.py` | Экраны «Прошивка», «Приложения», «Бэкап», «Трансляция» |
| `qt_mirror_controls.py` | Плавающая панель управления рядом с окном `scrcpy` |
| `pixel_tools_ops.py` | ADB/Fastboot-операции разделов и запуск `scrcpy` |
| `theme_tokens.py` | Загрузка Material 3 токенов без зависимости от GUI |
| `pixel_device_detector.py` | Бэкенд ADB/Fastboot без UI-зависимостей |
| `material-you-expressive.json` | Исходная палитра Material Theme Builder |
| `tools/` | Локальные `adb`, `fastboot`, `scrcpy` и их библиотеки |
| `main_flet.py` | Предыдущая версия интерфейса на Flet (не используется) |
